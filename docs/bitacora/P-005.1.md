### Consulta sobre la actualización de Node.js

**Mensaje original de los responsables**

```text
cómo actualizo node.js?
```

**Respuesta original de Codex**

En tu Windows, instala **Node.js 24.22.3 LTS**, la versión fijada en el `.nvmrc` del proyecto.

1. Descarga y ejecuta el [instalador oficial de Node.js 24.22.3 para Windows x64](https://nodejs.org/dist/v24.22.3/node-v24.22.3-x64.msi). Deja habilitada la opción **Add to PATH**.
2. Cierra PowerShell y abre una terminal nueva en la raíz del repositorio.
3. Comprueba la instalación:

   ```powershell
   node --version
   npm.cmd --version
   openspec.cmd --version
   openspec.cmd list
   ```

`node --version` debe mostrar `v24.22.3`. Para OpenSpec, lo esperado es `2.2.0` y `No active changes found.`

Si Node sigue mostrando `v22.14.0`, ejecuta `where.exe node`. La primera ruta de la lista identifica el ejecutable que está tomando la terminal.
